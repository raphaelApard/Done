# Done as a web app (PWA)

`pwa/` is a standalone, installable web version of Done. It reproduces the "Todo App v2" design from Claude Design: Broadsheet tokens, Instrument Sans, square cards with a progress ring, a square composer whose button grows into "Ajouter", and a light and a dark theme.

It shares nothing with the Flutter code except the app icons. Data is not synchronised between the two versions.

## Features

- **Projects** in a two-column grid, each with a progress ring, a done/total counter and a status line ("3 restantes"). The total of open tasks sits next to the title.
- **Tasks**: add several in a row, check off, edit by tapping the text (Enter saves, Escape cancels, an empty title removes the task), delete.
- **Reordering**: drag a row with the mouse, or drag the grip with a finger.
- **Completed section** that collapses, with "Effacer" to clear it.
- **Delete confirmation** in a bottom sheet for projects and tasks.
- **Themes**: follows the system. On a wide screen, the design's top bar ("Clair" / "Sombre") is shown above the app and the choice is remembered.
- **Offline and installable**: a service worker caches the app and its font, and the manifest lets browsers install it on the home screen.
- **Local persistence** in `localStorage`. The sample projects of the design are shown on the first visit.

The interface is in French.

## Layout

On a phone, the app fills the screen. The spacing the design leaves for the status bar and the home indicator becomes the safe-area insets of the device. From 600 px wide, the page reproduces the design canvas: the top bar, then the app in a 402 px wide rounded frame.

## Structure

```
pwa/
├── index.html            markup of both screens and the confirmation sheet
├── styles.css            Broadsheet tokens, dark overrides and the design's styles
├── app.js                rendering and interactions (keyed DOM updates, no framework)
├── store.js              state transitions, labels and persistence, without DOM
├── sw.js                 service worker (offline cache)
├── manifest.webmanifest
├── icons/                generated by tool/generate_icons.py
└── tests/store.test.js   unit tests for store.js
```

Rows are kept across renders and keyed by id, so the design's entry animations only play for new rows.

## Running and testing

Requirements: Python 3 to serve the files and Node.js 20 or later for the tests.

```bash
cd pwa
npm start   # python3 -m http.server 8080
npm test    # node --test
```

Open http://localhost:8080. A service worker only runs on `localhost` or over HTTPS. CI runs the tests in the `pwa` job.

## Deploying

Any static host works: publish the content of `pwa/` as is, over HTTPS. All paths are relative, so the app can live in a sub-folder (GitHub Pages, for example).

When you change the list of files in `sw.js`, bump `VERSION` so that installed copies drop the old cache. Changes to existing files reach users on the next launch after the update is downloaded.
