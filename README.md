## Features

- **Projects** with a tinted card, a progress ring and a status line ("3 restantes").
- **Tasks** you can add in a row, edit inline (tap the text), reorder by dragging the handle, check off and delete.
- **Completed section** that collapses, with a one-tap "Tout effacer".
- **Safe deletion**: projects and tasks are removed after a confirmation, and projects can also be swiped away.
- **Light and dark themes**: follows the system by default, with a toggle on the home screen.
- **Local persistence**: everything is saved on the device, no account and no network needed.

The interface is in French.

## Getting started

Requirements: [Flutter](https://docs.flutter.dev/get-started/install) 3.47 or later (Dart 3.13).

```bash
git clone git@github.com:raphaelApard/Done.git
cd Done
flutter pub get
flutter run
```

Pick a device with `flutter run -d <device>` (`flutter devices` lists them). Plus Jakarta Sans is fetched by `google_fonts` the first time the app runs, so the first launch needs a network connection.

The project has iOS, Android, macOS and web targets. It has been run and checked on the iOS simulator; the other targets are generated by `flutter create` and have not been tested by hand.

## Tests

```bash
flutter analyze
flutter test
```

The suite covers the models, the store (including persistence and corrupted data), the themes, the widgets and the main flows through the screens. CI runs both commands on every push and pull request.

## Project structure

```
lib/
├── main.dart               entry point and DoneApp (theme, locale, layout cap)
├── models.dart             Project and Task, JSON serialisation
├── store.dart              TodoStore: state and persistence (shared_preferences)
├── seed.dart               sample projects for the first launch
├── todo_scope.dart         gives widgets access to the store
├── theme.dart              light and dark themes, project tints
├── screens/
│   ├── home_screen.dart    project list
│   └── project_screen.dart task list
└── widgets/
    ├── check_circle.dart
    ├── composer.dart       floating "add" pill
    ├── confirm_dialog.dart
    └── progress_ring.dart
```

State lives in a single `ChangeNotifier`, exposed through an `InheritedNotifier`, so the app has no state-management dependency.

## Design

The UI is a port of the "Pastel" proposal made with Claude Design: Plus Jakarta Sans, pastel cards per project, a pill-shaped composer, and a dark variant.
